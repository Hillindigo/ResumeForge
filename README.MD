# ResumeForge

A long-term resume-building product, initialized from the CanvasEditor canvas
editing engine.

> **Current status:** product foundation. The present UI is the imported editor
> baseline; ResumeForge branding, product features, and service integrations will
> be developed independently.

## Product direction

ResumeForge will focus on building polished, privacy-respecting resumes with a
flexible canvas editor. Planned product layers can include template workflows,
account and cloud-save features, guided writing, collaboration, and paid services.

## Development

```bash
npm install -g pnpm@8.11.0
pnpm install
npm run dev:react
```
